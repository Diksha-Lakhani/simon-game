# Simon Game Project

A fun and interactive Simon Game built using HTML,CSS, JavaScript and JQuery. The game challenges players to memorize and repeat an increasingly long sequence of colors and sounds.

---

## Features

- Interactive gameplay with four colored buttons
- Random sequence generation
- Increasing difficulty with each successful round
- Sound effects for each button
- Visual button animations
- Level tracking during game play
- Game Over notification with restart functionality
- Responsive design
- Dedicated instructions and game-start page

---

## Technologies Used

- **HTML** – Structure of the game
- **CSS** – Styling
- **JavaScript** – Game logic
- **JQuery** - interactivity and animations
- **Node.js** – Runtime environment
- **Express.js** – Web server and routing
- **EJS** – Dynamic page rendering

---

## How to Play

1. Open the game and read the instructions.
2. Click Start Game to enter the game.
3. Press any key to begin the game.
4. Watch the sequence of colors shown by the game.
5. Repeat the sequence by clicking the colored buttons in the correct order.
6. Each correct round adds a new color to the sequence.
7. The game ends when you click the wrong color.
8. Press any key again to restart and try to beat your previous level.

---

## Game Logic

The game maintains two sequences:

- Game Sequence – randomly generated by the game
- User Sequence – colors selected by the player

After every successful round, a new random color is added to the game sequence. The player's input is checked against the corresponding position in the sequence. If the complete sequence is reproduced correctly, the next level begins. An incorrect input triggers the game-over state and resets the game.

## Installation

Clone the repository

```bash
git clone https://github.com/Diksha-Lakhani/simon-game.git
```

Navigate to the project

```bash
cd simon-game
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm start
```

The application will run on

```
http://localhost:3000
```
Open the URL in your browser and start playing.
